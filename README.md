# Organization Heatmap

An interactive world map showing how many partner organizations are in each country, with drill-down to states and provinces, and the organization names on hover or tap. Data comes live from a Google Sheet. The page is static, built on D3 and public-domain Natural Earth boundaries, hosted on GitHub Pages, and embedded in the website through an iframe.

Full documentation is written in a later task. See `openspec/changes/org-heatmap/` for the proposal, design, and specs.
